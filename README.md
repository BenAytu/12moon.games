# 12moon.games

Static website for 12 Moon Games (TV Mirror guides, games, privacy pages).

- Source of the pages: `_build/build.py` → `python -I _build/build.py .` regenerates them.
- `tv-mirror/privacy/` and `tv-mirror/terms/` are copied from the TV Mirror project.
- Hosted on GitHub Pages; `ads.txt` and the `google-adsense-account` meta tag are for AdSense verification (no ads are shown).
